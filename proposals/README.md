# Proposals

Design drafts that are too long for an ADR. Pair with a short ADR
in `../decisions/` that decides the question; the proposal here
carries the supporting specification.

ADRs are journal entries (status, what, why, consequences).
Proposals are specifications (layout, contracts, call-site maps,
test plans, migration ordering). Both can grow as the work lands;
once the implementation is stable the proposal can be retired into
the consuming repo's `docs/`.
